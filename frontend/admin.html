📸 Create Snapshot

💡 What is a Snapshot?
A snapshot saves ALL current configuration settings (LLM, Database, Email, Scheduler, Insights, Export) at this moment. You can restore any snapshot later to quickly rollback to a known working state.

Use Cases:
  • Before production deploys
  • Before major config changes
  • To save different environment configs
  • For quick rollback if something breaks

♻️ Restore Snapshot

⚠️ Warning:
Restoring a snapshot will replace ALL current configuration with the saved snapshot state. This includes LLM, Database, Email, Scheduler, Insights, and Export settings.

Recommended: Create a new snapshot before restoring, so you can rollback if needed.

📋 Example Workflow

// Before deploying to production
1. Create snapshot: "stable_v1.5_prod"

// Make changes
2. Update LLM model to Claude Sonnet 4
3. Change database host to new server
4. Enable insights engine
5. Hot reload providers

// Test in production
6. Monitor for 10 minutes...

// Oops! Users reporting errors 😱
7. Restore snapshot: "stable_v1.5_prod"
8. Auto hot reload
9. ✅ Everything back to normal in 30 seconds!
